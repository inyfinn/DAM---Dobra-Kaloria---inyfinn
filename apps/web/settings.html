Ustawienia

Preferencje interfejsu i integracji

Ścieżka bazowa dysku

To Twoje ustawienie (konto / profil). Aplikacja nie narzuca stalej litery dysku. Folder musi zawierac -- ARCHIWUM --, - EKSPORT, - POLSKA. Przycisk "Wykryj automatycznie" tylko podpowiada - nie zapisuje sam.

Okno aplikacji

Zamyka bieżące okno DAM ETA i uruchamia je ponownie (desktop). Przydatne po zmianie sciezki lub gdy UI sie zawiesi.

Instrukcje programu (baza)

Newralgiczne ustalenia (status F/X/D, nazewnictwo, zakazy). Zapisane w Postgres dam_kv_store.program-instructions. Agent i kod muszą tego przestrzegać - to nie jest opcjonalna notatka.

Nazewnictwo nośników

Zasada programu zapisana w bazie (dam_kv_store → naming-dictionary + app-settings) i w słowniku lokalnym. Nie jest to przełącznik użytkownika — obowiązuje zawsze.
