# ADR-001 - Stack v1

Status: Accepted  
Date: 2026-07-16

## Decision

Laravel 11 API + PostgreSQL + UI Geex z `P:\DAM\THEME` + desktop pywebview.

## Why

- PHP portable juz na P; Composer OK.
- Geex daje gotowy admin shell (file-manager) zamiast budowac Next skin.
- Desktop jak Inyfinn: prawdziwa lokalna app, ten sam localhost dla browser.

## Consequences

Zakaz Next.js jako glownego skina v1. Tokeny tylko z Geex variables.
