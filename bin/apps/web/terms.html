Regulamin korzystania

    DAM ? obowiązuje od 2026-07-18

    1. Przedmiot

    DAM to wewnętrzna aplikacja desktop/web do zarządzania plikami marketingowymi, checklistą kompletności i zgłoszeniami. Nie jest usługą publiczną typu SaaS dla osób trzecich.

    2. Konta i role

    • user - przeglądanie, zgłoszenia JSON (propozycje / zapotrzebowanie).
    • power_user - jak user + operacje robocze bez zatwierdzania kanonicznej bazy.
    • admin - zatwierdzanie zmian, integracje, użytkownicy, infrastruktura.

    3. Zasady pracy

    Zabronione: udostępnianie haseł, obchodzenie kontroli ról, masowe kasowanie bez zgody admina, wynoszenie danych poza kanały firmowe. Pliki Marketing pozostają własnością organizacji.

    4. Integracje zewnętrzne

    Połączenie Asana / Microsoft (Teams, Outlook) wymaga osobnego zalogowania i zgód (patrz Zgody). Operator nie gwarantuje dostępności API stron trzecich.

    5. Odpowiedzialność

    Aplikacja dostarczana „jak jest” w ramach wdrożenia wewnętrznego. Backup i retencja - zgodnie z procedurę IT. Użytkownik zgłasza błędy administratorowi.

    6. Zmiany regulaminu

    Aktualizacje publikowane w aplikacji. Dalsze korzystanie oznacza akceptację nowej wersji, o ile prawo nie wymaga osobnej zgody.
