# tooling - wszystko na P:\DAM

| Folder | Przeznaczenie |
|--------|----------------|
| `downloads/` | Instalatory, ZIP (PHP, Postgres, ...) |
| `choco-cache/` | Cache Chocolatey |
| `npm-cache/` | `npm_config_cache` |
| `composer-home/` | `COMPOSER_HOME` + cache |
| `bin/` | Portable: `php/`, `pgsql/`, `composer.phar`, bat wrappers |

Nie uzywaj AppData ani TEMP jako miejsca projektu.
